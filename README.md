
# Droppy – Desktop Water Reminder Pet 💧

Droppy is a small desktop companion application designed to remind users to stay hydrated while working or studying.

## Features

- 🐾 Animated desktop pet
- 💧 Water reminder concept
- 🖱️ Click interaction
- ✋ Draggable desktop window
- 🪟 Transparent and frameless UI
- 📌 Always-on-top desktop window
- 💾 Persistent window position

## Technologies Used

- HTML
- CSS
- JavaScript
- Electron

## Project Overview

Droppy was created as a desktop companion project using web technologies with Electron.

The project focuses on desktop UI behavior, user interaction, window positioning and creating a lightweight animated companion experience.
